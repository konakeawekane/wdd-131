Overview

Purpose

The purpose of this website is to provide a simple and easy to use interface to allow individuals to experiemnt with procedural art coming up with there own ideas and processes for art genoration. This allows individuals to learn about and gain experiance with procedural processes and art.

Audience

My audiance is more novice programmers and artists who enjoy experimenting with new techiques to create art. These people will not need any programming experiance and will only need to bring their creativity to see results.

Dynamic elements

Several different dynamic elements will be used. For the rendering processes I will be using a canvas element with a 2D rendering context, for the instruction processing and management I will be using a object array, and for temporarlly storing values I will be using a single object and uses map object functions to treat it like a dictionary. When drawing the instruction object array will be looped over using a forEach method. Buttons on the page will allow the addition, removal, and modification of buttons on the screen.
